title: "重味超核物理粲超核与底超核"
category: 超核物理
date: 2026-05-10
---
1977年，有人问了一个看起来很超前的问题：把一个粲夸克塞进原子核里，核还抱得住它吗？

这个问题提得太早了。那时候粲夸克被发现才三年，Λc+（含一个粲夸克的最轻重子）都还没被确认。但问题的逻辑是清楚的：如果你把核里的一个上夸克或下夸克换成粲夸克，你就造出了一个全新的原子核——粲超核。普通超核把奇异夸克换进去，已经被实验做了六十多年。粲夸克比奇异夸克重十倍，它的行为一定不同。问题是，怎么不同？

回答这个问题需要过三道关。第一，粲重子跟核子之间的力到底有多强——吸引还是排斥，势阱有多深。第二，就算力是吸引的，粲重子能不能在核里待住——它自己会不会衰变掉。第三，即使理论上一切成立，怎么在实验上造出粲超核并认出它来。

先说力的问题。

Λc+在核物质里感受到的势阱深度，理论给出的数字散得很。最乐观的估计大约-30 MeV，跟Λ超子在核里的势阱差不多深。最保守的估计只有-10 MeV上下，浅得几乎兜不住。差别从哪来？Λ超子的势阱深度大约-30 MeV，这是几十年实验测出来的——从最轻的³_ΛH到²⁰⁸_ΛPb，跨了整个核素图，数据密密麻麻。Λc+没有这些数据，因为从来没有人做出来过粲超核。理论只能从夸克模型或者手征有效场论外推。

夸克模型给出的图景是这样的：Λc+里那个粲夸克太重了，它几乎不动，像一颗铅球钉在重子中心。跟核子交换的介子还是那些——π、σ、ρ、ω——但交换过程中粲夸克参与不了，因为介子只在轻夸克之间传递。这意味着介子交换的强度被削弱了——少了一个参与者，力就弱了一截。另一方面，粲夸克的质量本身会产生一种"重排效应"——核物质的密度分布因为Λc+的存在而重新调整，这个调整本身可以贡献额外的吸引。2024年，兰州近物所的团队用密度依赖相对论平均场理论详细算了重排效应，发现它对轻粲超核的影响尤其大，甚至能决定一个Λc+到底能不能被兜住。

```
  力的来源：Λc+ vs Λ
  ===================

  Λ (奇夸克):
    奇夸克质量 ~ 500 MeV
    介子交换：u,d,s 全参与 → 势阱 ~ -30 MeV
    实验数据：丰富 (A=3 到 208)

  Λc+ (粲夸克):
    粲夸克质量 ~ 1500 MeV
    介子交换：只有 u,d 参与 → 削弱
    重排效应：额外吸引 → 补偿
    势阱估计：-10 ~ -30 MeV
    实验数据：零
```

手征有效场论给出的ΛcN相互作用是吸引的，但比ΛN弱。Haidenbauer和Kreuzer在2019年的系统计算表明，ΛcN的¹S₀相移大约只有ΛN的一半。不过手征方法也有自己的不确定度——高阶项的系数靠拟合，而拟合的数据在粲区基本不存在。

格点QCD理论上可以给终极答案，但计算代价极高。HAL QCD合作组在2018年第一次算了ΛcN相互作用，用的格点参数对应的π子质量还是410到700 MeV——离物理值140 MeV差得很远。外推到物理π子质量后，ΛcN是吸引的，但能否形成束缚态取决于不确定度范围。更近物理点的计算正在推进，但到2026年初还没有发表。

还有一个更根本的问题：即使ΛcN的二体相互作用是吸引的，Λc+能不能跟两个以上的核子形成稳定的束缚系统？2003年南开大学团队的论文标题直接问"粲超核能不能存在"，结论是如果Λc+的势阱深度大于20 MeV，粲超核就可以存在——但如果只有10 MeV，就很悬了。2023年，另一团队用变形的Skyrme-Hartree-Fock方法系统算了从最轻到最重的粲超核，发现Λc+的1s态在A≈12以上才能束缚，1p态需要A≈40以上。而且由于库仑排斥——Λc+带正电——很重的粲超核可能反而兜不住，存在上限大约在A≈200附近。

这就是重味超核最恼人的地方：你连它存不存在都不确定，因为缺的不是理论，是数据。

第二道关是Λc+自己的寿命。Λc+通过弱作用衰变，寿命大约200飞秒。这个时间看起来短，但在核物理的尺度上其实不算太短——强作用过程发生在飞秒到仄秒之间，Λc+有足够的时间"感受"核势阱。如果它真的被束缚了，在衰变之前它可以在核里待上几十到几百圈。问题不是它活不长，而是你很难在它衰变之前找到足够多的Λc+来做一个统计上有意义的测量。

第三道关是实验。这是整个领域最头疼的部分。

目前世界上没有一台正在运行的加速器能够批量制造粲超核。但至少有三条路线正在逼近。

第一条路线在德国达姆施塔特。FAIR设施的PANDA实验用反质子打核靶。反质子跟核内的一个质子湮灭，产生粲夸克对，其中一个粲夸克有机会跟核内残余的核子结合，形成Λc+或者粲超核。Shyam和Tsushima在2017年的理论计算表明，用反质子打¹⁶O靶，产生的粲超核⁽Λc⁾O¹⁶的截面在几 nb到几十 nb之间——极小，但PANDA的高亮度反质子束有可能弥补。关键优势：PANDA不需要额外产生D介子，反质子湮灭本身就是粲工厂。FAIR目前在建，PANDA预期2030年前后开始取数。

```
  制造粲超核的三条路线
  =====================

  [PANDA/FAIR]           [J-PARC E50]          [ALICE/LHCb]
   反质子湮灭             高能π束打靶            重离子碰撞
   不需额外D介子          粲重子谱学             Λc+产生率最高
   截面 ~ nb              截面未知               但难以形成束缚态
   2030前后               2020s后期             已运行
       |                      |                     |
       v                      v                     v
   优势: 最干净          优势: 束流强          优势: 已有数据
   劣势: 还没建好        劣势: 需要新束线      劣势: QGP环境复杂
```

第二条路线在日本。J-PARC的E50实验计划用50 GeV质子束打靶产生高能π束，通过πN反应产生粲重子。J-PARC已经在奇异超核上取得了里程碑式的成果——2019年E07合作组在核乳胶里观测到⁽ΛΛ⁾Be¹⁰，这是双Λ超核的清晰证据。但粲区需要的束能量远高于奇异区，E50需要新的束流线和探测器。日本的Hadron Hall扩建计划中包含了粲谱学的束线，时间表在2020年代后期。

第三条路线最反直觉：用相对论重离子碰撞。ALICE在LHC上测量到pp和Pb-Pb碰撞中Λc+的产生截面出人意料地大——Λc+/D⁰的产额比远高于理论预期，这意味着在夸克-胶子等离子体中，粲夸克跟轻夸克结合成重子的概率比之前认为的高很多。2024年8月，STAR合作组在Nature上发表了反超氢-4核（⁽Λ̄⁾H̄⁴）的观测结果——这是迄今发现的最重的反物质超核，包含一个反Λ、一个反质子和两个反中子。重离子碰撞是产生奇异超核的天然工厂，但粲超核是另一回事：粲夸克对在碰撞早期产生，然后要在夸克-胶子等离子体冷却后恰好跟核子结合，概率极小。不过ALICE的Λc+产额数据暗示这条路也许不是完全不可能。

2024年还有一个新想法被提出：用反质子-核碰撞直接产生粲超核，不需要先产生D介子。这个方法的关键是利用反质子跟核内核子的湮灭直接产生粲夸克对，跳过了D介子这个中间步骤，理论估计截面可以提高一个量级。

把目光从粲再往重处挪——底夸克。

底超核——把核里的轻夸克换成底夸克——在所有方面都更极端。Λb的质量大约5620 MeV，是Λc+的将近两倍，是核子的六倍。Λb在核物质中的势阱深度，理论估计比Λc+更深，因为底夸克更重，重排效应更强。夸克-介子耦合模型给出的Λb势阱深度大约-40到-50 MeV——比Λc+深，甚至比Λ超子还深。这意味着底超核可能比粲超核更容易存在。

但底超核的实验前景更暗淡。Λb的寿命大约1.5皮秒，比Λc+长，但Λb的产生截面比Λc+小一到两个量级——底夸克的质量太大，需要更高的碰撞能量。在LHC上，ALICE和LHCb确实看到了Λb，但数量远不足以形成超核。PANDA在FAIR上也许有机会，但需要更高的反质子束能量。

还有一个更深层的物理理由让人关心底夸克在核里的行为：重夸克对称性。粲夸克和底夸克都足够重，以至于在许多情况下，它们的自旋取向不影响强作用的主体结构——这叫重夸克自旋对称。如果这个对称在核介质中仍然成立，那么Λc和Λb在核里的行为应该可以用同一套理论框架描述，只是质量尺度不同。检验这一点需要粲区和底区都有数据。现在两边都没有超核数据，所以这个对称性在核介质里到底好不好，没人知道。

但重味超核物理不只有"超核"这一种玩法。还有一类更奇特的东西：把整个粲偶素——J/ψ或者ηc——塞进核里。

这个想法的来源可以追溯到1980年代。Brodsky和Miller等人提出，J/ψ和核子之间通过QCD范德瓦尔斯力相互吸引——多重胶子交换产生的纯色力。如果这个吸引力足够强，J/ψ可以在核里形成一个束缚态，核的尺寸几乎不变，因为J/ψ太小了——它的半径大约0.5 fm，只有核子的四分之一。塞进核里，它就像一颗铅球丢进游泳池，池子纹丝不动，但铅球确实沉在池底。

2024年底，HAL QCD合作组在格点QCD上首次计算了核子-粲偶素相互作用。结果：J/ψ-N和ηc-N的相互作用在所有距离上都是吸引的，包含中心力、自旋-自旋力和张量力四个分量。2025年，同一团队基于这个格点QCD势，用三体集团模型计算了cc̄+α+α系统——把一个粲偶素塞进⁹Be。结果发现，⁽cc̄⁾Be⁹在基态可能有一个约1 MeV的束缚能——很浅，但确实束缚。2025年底，PRL上发表了基于HAL QCD势的更系统的计算，确认了cc̄+核系统存在束缚态的可能性。

```
  三种重味核系统
  ===============

  类型 I: 粲超核
    Λc+ 替代核子 → ⁽Λc⁾Li⁷
    势阱 ~ -10 到 -30 MeV
    关键问题：势阱够不够深？

  类型 II: 底超核
    Λb 替代核子 → ⁽Λb⁾Li⁷
    势阱 ~ -40 到 -50 MeV
    关键问题：产生截面太小

  类型 III: 粲偶素-核束缚态
    J/ψ 嵌入核内 → ⁽cc̄⁾Be⁹
    势阱 ~ 几 MeV (QCD范德瓦尔斯力)
    关键问题：束缚太浅，怎么探测？
```

粲偶素-核束缚态如果真的存在，它的重要性远不止于"又一个新奇核"。J/ψ在夸克-胶子等离子体中会被"熔解"——这是QGP诊断的经典信号。但如果J/ψ在冷核物质里就被束缚了，那它的"失踪"就不全是QGP的锅——部分原因可能是核吸收。区分这两者需要精确知道J/ψ-核相互作用的强度。这正是粲偶素-核束缚态研究要回答的问题。

2026年3月17日，LHCb宣布了一个跟粲超核间接相关但同样重要的结果：升级后的LHCb探测器在Run 3数据中首次观测到双粲重子Ξcc+。2017年LHCb发现了Ξcc++（ccu），那是人类第一次看到含两个粲夸克的重子。现在它的同位旋伙伴Ξcc+（ccd）也被确认，质量3619.97 MeV，统计显著性超过7σ。这意味着双粲重子不再是单个事件的巧合，而是一个完整的多重态。对于粲超核物理，双粲重子的存在打开了一个新维度：如果你能把一个Ξcc+塞进核里——不是换一个粲夸克，而是换两个——核的行为会怎样？两个重夸克的"铅球效应"会不会让势阱更深？理论计算已经开始探索双粲双核子态（doubly charmed dibaryon），但结论还很初步。

再退一步看，整个重味超核物理的根本动机是什么？

不是造新奇核。是理解QCD在非微扰区间的行为。

QCD在低能区是强耦合的，微扰论失效。理解核力需要非微扰方法——格点QCD、有效场论、密度泛函。但这些方法在核子-核子相互作用上已经被校准到极高精度，我们没有多少新的"自由度"来检验它们的泛化能力。重味夸克提供了一个干净的新变量：你把一个夸克的质量从几个MeV跳到1500 MeV甚至4700 MeV，看理论能不能跟上。如果能，说明我们对QCD非微扰的理解是对的。如果不能，我们就找到了理论裂缝。

具体来说，重味超核物理连着三个更深的问题。

第一，夸克质量对核力的影响到底有多大？ΛN和ΛcN都是介子交换主导的，但介子交换的强度跟参与夸克的质量和味道有关。从ΛN到ΛcN，力变弱了多少？从ΛcN到ΛbN，力又变强了多少？这些变化能不能被夸克模型或者手征有效场论统一描述？

第二，重排效应和介质修正有多重要？Λc+在核物质中不是一个被动的"铅球"。它的存在会改变核物质的介子场分布，反过来这些改变又影响Λc+自身的束缚。这种自洽循环在轻核里可能决定Λc+到底能不能被束缚。2024年兰州的DDRMF计算第一次定量分析了这个效应，结论是重排项不可忽略。

第三，超子谜题的下一层。中子星内部可能存在奇异物质，Λ超子的出现使状态方程软化，导致最大质量低于2M⊙的观测值——这就是超子谜题。但如果中子星更深处出现了粲核子甚至底核子呢？虽然目前认为中子星密度不够高到产生开粲，但重味自由度对状态方程的影响还没有被系统研究过。而且如果重味核物质真的在某些致密天体中存在，它的性质将取决于我们现在正在算的那些ΛcN和ΛbN相互作用参数。

2025年5月，一篇发表在EPJA上的论文综述了含奇异和重味夸克的核系统中的重子-重子相互作用，明确把粲和底重子跟核子的作用放在了同一个理论框架里。这反映了领域的共识：奇异、粲、底三个味道区的核物理不应该被割裂研究，它们是同一个QCD故事在不同质量尺度的投影。

回到那个1977年的问题。将近五十年过去了，粲超核还没被做出来。但我们现在对ΛcN相互作用有了格点QCD的计算、手征有效场论的预测、夸克模型的估算。我们知道Λc+的势阱深度在-10到-30 MeV之间——最乐观的情况下粲超核存在，最悲观的情况下它不存在。我们知道PANDA和J-PARC可能是最先看到它的实验。我们知道粲偶素跟核子之间有来自格点QCD的吸引力。我们知道双粲重子Ξcc+已经被确认。

我们不知道的是：那20 MeV的势阱深度到底落在哪里。10 MeV还是30 MeV，是粲超核存亡的分界线。这个数字，只有实验能给。
