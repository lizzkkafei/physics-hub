银河系里最频繁的爆炸不在恒星内部，而在恒星表面——中子星表面。每隔几小时到几天，一颗正在"吃"伴星物质的中子星就会打一次嗝，释放出的能量相当于太阳一整年的辐射，持续十秒到几分钟。这就是I型X射线暴。

打嗝的机制很直接。伴星的氢和氦物质流到中子星表面，堆成一层约十米厚的大气。重力把这一层压到十亿个大气压，温度升到两亿度。氢通过热CNO循环慢慢烧着，像一锅温水。但氦在底下越积越多，直到某个临界点——氦点燃了，温度飙升，CNO循环加速，氦聚变跟上，整层大气瞬间变成核反应的火焰风暴。这就是热核失控。

失控的核心是一串连珠炮一样的核反应：rp过程。

rp是"快质子俘获"的缩写。过程很简单——一个原子核吞掉一个质子，变成更重的核，再吞一个，再变重，一路沿着质子滴线往上爬。质子滴线是原子核能拴住质子的极限边界，越靠近它，核越不稳定，半衰期越短。rp过程里经过的核大多在这个边界附近，寿命从毫秒到几秒，在地球上根本不存在——只有中子星表面的极端环境才能让它们成批出生又成批衰变。

但这条上坡路不是畅通的。

```
  质子数 Z
  ^
  |                                    .. 72Kr
  |                                 ..    |
  |                              ..       v [等待]
  |                           .. 68Se
  |                        ..    |
  |                     ..       v [等待]
  |                  .. 64Ge
  |               ..    |
  |            .. 56Ni <-- 铁峰，起点
  |         ..
  |      ..  热CNO循环产物
  |   ..
  +------------------------------------> 质量数 A
     rp过程路径示意
```

三块大石头横在路上：64Ge、68Se、72Kr。它们叫"等待点核"。问题出在它们的质子俘获产物——65As、69Br、73Rb——太不稳定了，刚吞进去的质子立刻又被吐出来。核走到这里，进退不得，只能等β+衰变把质子变成中子，才能绕过去。但β+衰变慢，64Ge的半衰期是63.7秒，68Se是35.5秒，72Kr是17.2秒。整个X射线暴也就持续10到100秒，在等待点上耗掉的时间跟暴发总时长差不多。所以这三个等待点直接决定了暴发的光变曲线、能量输出、最终产物的丰度。

这就是核物理学家过去二十年最头疼的问题：等待点上到底发生了什么？

答案藏在原子核的质量里。

质子俘获的概率跟Q值指数相关，Q值又由两个核的质量差决定。差个几十keV，反应率就能差几倍甚至几十倍。但65As、66Se这些核太远离稳定线，质量数据要么没有，要么误差大得吓人。2023年之前，65As的质子分离能Sp的测量值是-90(85) keV——负值意味着质子不束缚，但误差大到它也可能是束缚的。一个核到底能不能拴住质子，直接决定了64Ge是畅通的通道还是堵死的路口。

2023年，中国科学院近代物理研究所在兰州的重离子加速器冷却储存环（HIRFL-CSR）上完成了一次关键实验。

```
  +-----------------------------------+
  |    HIRFL-CSR 等时质谱术           |
  |                                   |
  |  初级束 --> 靶 --> 碎片 --> CSR   |
  |                          |        |
  |          Bρ-IMS 技术     |        |
  |          同时测量回旋周期+速度     |
  |                    |              |
  |          质量分辨本领 ~160,000     |
  |                    |              |
  |          64As: 仅6个离子!         |
  |          仍测得 δm/m ≈ 1.8×10^-6  |
  +-----------------------------------+
```

团队用一种叫Bρ-定义等时质谱术的新方法，测量了63Ge、64As、65As、66Se、67Se五个核的质量。其中64As在两周的实验里只观测到6个离子——大约每三天一个——但仍然测出了精确质量。66Se和37Cl的质荷比几乎一模一样，团队利用电荷依赖的信号振幅差异把它们区分开。

结果炸了锅。

65As的质子分离能Sp被确定为-221(42) keV——明确不束缚。这意味着64Ge吞下质子变成65As后，质子几乎立刻被弹回，单质子俘获这条路被堵死了。66Se则比预期更束缚，双质子俘获通道64Ge(2p,γ)66Se比原来想的稍微容易一些，但仍然困难。

综合效果：rp过程在64Ge处的瓶颈比之前认为的更强。这个过程叫"慢下来"效应。以前的单区域模型以为64Ge不算什么瓶颈，但兰州的数据加上多区域MESA模拟后，结论反转——64Ge确实是堵墙。

多区域模拟还揭示了一个单区域看不到的现象。64Ge处燃烧放缓，氢被保留下来，通过对流混合送到更深层继续燃烧，导致暴发峰值流量更高、尾巴更长。用这个新模型去拟合"时钟暴"GS 1826-24的观测光变曲线，需要把距离调大约6.5%（从5.8到6.2 kpc），把中子星的致密度（1+z）调低——意味着这颗中子星可能没有之前以为的那么致密。

```
  质量测量 → Sp(65As) = -221 keV
       |
       v
  64Ge瓶颈更强 → 氢保留更久
       |
       v
  对流混合 → 峰值更高、尾巴更长
       |
       v
  拟合GS 1826-24 → 距离+6.5%, 致密度降低
       |
       v
  中子星状态方程约束受影响
```

但这不是故事的结尾。2025年，Meisel等人在ApJ上发表了一篇论文，标题直接点题："质子滴线附近的增强核结合打开了64Ge等待点的可能旁路"。他们发现，64As吞下质子变成65Se这条路径可能比之前估算的更通畅。关键在于65Se的核结合比理论预测的更强——如果真是这样，最高可达36%的rp过程物质流可以从64Ge旁路绕过。这意味着64Ge这个瓶颈可能不是死墙，而是有一扇半开的门。

但65Se的质量至今没有实验测量值。Meisel在论文最后明确呼吁：急需测量65Se的质量和β缓发质子发射分支比。这是下一步的关键。

64Ge是最著名的等待点，但它不是唯一一个。上游的"门"同样重要。

rp过程的起点是热CNO循环的产物。CNO循环像一台引擎，把氢变成氦，催化剂是碳氮氧。温度足够高时，这台引擎会"突破"——15O(α,γ)19Ne或14O(α,p)17F把物质流从CNO循环泵入rp过程。突破的速率直接决定了暴发能不能真正启动、启动多猛。但19Ne和18Ne的关键共振态位置至今没有定论，15O(α,γ)19Ne的反应率在不同估算之间差了几个量级。这是X射线暴核物理里最古老的未解问题之一，从上世纪90年代就开始争论。

22Mg(α,p)25Al是另一个关键反应，控制着从A≈22区域向上流动的速率。2020年，密歇根州立大学团队用主动靶时间投影室首次直接测量了这个反应，发现反应率比统计模型预测的高了好几个量级。2023年，另一团队在PRL上报告了更精确的测量，反应率比2020年的直接测量结果又高了一个因子。新的反应率使得22Mg等待点的瓶颈效应减弱，物质更容易向上流。

中国的贡献不止于64Ge附近的质量测量。2025年底，近代物理所团队在ApJ上发表了26P和27S的精确质量测量。26P(p,γ)27S反应是rp过程在磷-硫区域的一个分支，之前因为质量数据不足，这个分支的重要性争论了多年。新数据表明，27S的质子分离能比之前以为的高129到267 keV，反应率在0.4到2 GK温度范围内被显著增强，1 GK处可达之前估算的5倍。rp过程在磷-硫区域的路径因此更加确定。

2025年4月，RIKEN的团队在MR-TOF质谱仪上做了另一组关键测量：84Mo、88Ru和78Y同核异能态的质量是首次实验确定。这组数据直接否决了一个在rp过程终点附近悬了多年的假说——Zr-Nb循环。

```
  rp过程走向终点...
       |
       v
  A ≈ 84 附近
       |
       +--> 84Mo的α分离能 Sα = 1.434(83) MeV
       |         |
       |         v
       |    Zr-Nb循环不可能形成
       |         |
       |         v
       |    rp过程不在A≈84处终止!
       |         |
       |         v
       +--> 物质流继续向更重核前进
              |
              v
         终点在哪里? → SnSbTe区域? (A≈100-110)
```

Zr-Nb循环的设想是：在84Mo附近，锆和铌的同位素之间形成一个闭合的反应循环，把物质流困住，让rp过程提前终止。如果真是这样，X射线暴就不能合成比A≈84更重的核。但新的质量数据表明，84Mo的α分离能Sα = 1.434(83) MeV，这个值使得循环根本无法形成。rp过程不被困在84Mo，物质可以继续往更重的方向走。

那终点到底在哪？目前的共识是rp过程很可能终止在锡-锑-碲（SnSbTe）区域附近，A≈100到110。但确切路径和终点丰度仍然高度依赖那些还没测到的核的质量和反应率。2026年初，RIKEN的CRISMASS项目在零度多反射飞行时间质谱仪上测量了质子富集的Rh、Pd、Cd同位素质量——这些正好处在rp过程终点附近的区域。

```
  全球实验平台布局
  ==================

  [HIRFL-CSR]          [FRIB-LEBIT]
   兰州,中国            密歇根,美国
   Bρ-IMS等时质谱       Penning阱 + MR-TOF
   64Ge区, 26P/27S      103Sn等质量
       |                    |
       v                    v
  [RIKEN MR-TOF]       [GSI/FAIR]
   埼玉,日本            达姆施塔特,德国
   84Mo区, Rh/Pd/Cd     储存环质谱
       |                    |
       v                    v
  [HIAF] ← 2025年调试中
   惠州,中国
   世界最高脉冲强度束流
   精确多功能核质谱仪
```

所有这些实验数据最终汇入一个数据库：JINA REACLIB。这是核天体物理的标准反应率库，包含几千个核反应的速率参数化公式。2026年3月，Schatz等人在Physics Reports上发表了92页的X射线暴核物理综述，把32个基于实验的新反应率加入了REACLIB，还为没有实验数据的反应提供了一套新的统计模型反应率。这是该领域近十年来最全面的一次数据库更新。

但数据好不等于模型好。X射线暴模拟还面临一个根本性的困难：对流。

暴发期间，中子星表面的燃烧层是对流不稳定的——热核燃烧产生的能量驱动对流，把新鲜的燃料带到燃烧区，把产物带走。一维模型用混合长理论近似处理对流，但这只是参数化的粗略方案。三维模拟显示，对流结构远比一维模型假设的复杂，燃烧前沿不是球对称推进，而是像火焰一样不规则蔓延。这直接影响了暴发的上升时间和峰值光度，也可能解释暴发振荡的起源——在暴发光变曲线中观测到的几百赫兹的亮度调制，频率接近中子星的自转频率。

2024年，NICER望远镜在4U 1820-30的暴发中探测到716 Hz的振荡信号，置信度2.9σ——如果被后续观测确认，这将是理解暴发不对称性和中子星自转的关键线索。2026年初，另一个团队在SRGA J144459.2-604207的暴发中也发现了暴发振荡。

暴发振荡的意义在于：它可能对应中子星表面的"热点"，由燃烧不对称性或磁场引导产生。如果振荡频率就是自转频率，我们就能直接测量中子星的自转周期。结合光球半径膨胀暴发（PRE暴发）测量的距离和爱丁顿光度，再配合rp过程模型约束的中子星致密度，我们就有了独立估算中子星质量和半径的途径。

```
  X射线暴 ↔ 多信使约束中子星
  ============================

  光变曲线 ──────→ rp过程模型 ──────→ 中子星致密度
      |                                    |
      v                                    v
  峰值光度 ──→ PRE距离 ──→ 爱丁顿光度 → 质量-半径
      |                                    |
      v                                    v
  暴发振荡 ──→ 自转频率 ──→ 表面不对称性
      |                                    |
      v                                    v
  灰烬成分 ──→ 壳层加热/Urca冷却 ──→ 壳层温度剖面
                                              |
                                              v
                                      超暴点火条件 → 浅加热
```

灰烬的问题值得一说。rp过程烧完之后，剩下的核灰烬被后续吸积的物质压入中子星壳层。灰烬的成分——特别是A=64附近的丰度——会深刻影响壳层的热演化。A=64丰度高意味着更多的电子俘获加热，A=65丰度低意味着更少的Urca冷却（电子俘获-β衰变循环产生中微子带走热量）。兰州的质量测量让A=64丰度上升17%、A=65下降14%，净效果是壳层更暖——这影响我们对超暴（superburst，碳点燃的极长X射线暴）点火条件的理解。

超暴是X射线暴的"大哥"。普通暴发是氦失控点燃，持续几十秒；超暴是壳层深处碳失控点燃，持续几小时到一天，能量是普通暴发的一千倍。超暴的点火条件对壳层温度极其敏感，而壳层温度又取决于rp过程灰烬的成分。所以一个在A≈64处的等待点核质量测量，可以一路影响到壳层深处碳的点燃——这就是核天体物理的蝴蝶效应。

还有一类更基本的限制：反应率的不确定性怎么传播到最终预测？2025年底，一个团队首次对X射线暴核合成做了全面的蒙特卡洛模拟，把所有反应率的不确定性同时扰动，看最终丰度分布的变化范围。结果发现，某些核的丰度不确定性高达一个量级以上，主要的误差来源集中在少数几个关键反应上。这说明，虽然我们已经测了很多质量，但还有少数反应率是短板——它们不确定，整个预测就不确定。

未来的路怎么走？

```
  X射线暴核物理: 前沿问题树
  ============================

  [等待点]
   ├── 64Ge旁路: 65Se质量急需测量
   ├── 68Se: 69Br/70Br质量未定
   └── 72Kr: 73Rb/74Rb质量未定

  [突破反应]
   ├── 15O(α,γ)19Ne: 共振态位置仍不确定
   └── 14O(α,p)17F: 需要更精确的共振强度

  [终点]
   ├── Zr-Nb循环已否决 → 终点更远
   ├── SnSbTe区域: Rh/Pd/Cd质量刚开始测
   └── 轻p核(92Mo, 96Ru)起源: X射线暴贡献?

  [模拟]
   ├── 3D对流: 燃烧不对称性
   ├── 暴发振荡机制: 热点 vs 模式
   └── 蒙特卡洛不确定性量化

  [装置]
   ├── FRIB (运行中): 1000+放射性核束
   ├── HIAF (调试中): 世界最高脉冲强度
   ├── RIKEN RIBF (运行中): MR-TOF + BigRIPS
   └── FAIR (建设中): 储存环 + 质谱
```

美国的FRIB（稀有同位素束流装置）2022年开始运行，能产生1000多种地球上从未存在过的放射性核束。它的LEBIT设施用Penning阱和MR-TOF做质量测量，已经测了103Sn等关键核。日本RIKEN的RIBF持续产出84Mo区和rp过程终点区的质量数据。德国GSI的FAIR正在建设中，建成后储存环质谱的能力将大幅提升。

中国的HIAF（强流重离子加速器装置）在惠州建设，2025年开始调试。它的核心卖点是"世界最高脉冲强度"和"最精确多功能核质谱仪"——这正是rp过程等待点核质量测量最需要的。HIAF能产生HIRFL-CSR无法企及的束流强度，有可能测到65Se这样至今无法触及的核。如果HIAF真的测出了65Se的质量，64Ge等待点到底有没有旁路，将会有一个明确的答案。

回看全貌，X射线暴是银河系里最常见的爆炸，也是唯一一个我们能同时用天文观测和核物理实验两端去约束的天体物理场景。中子星表面的一把火，从CNO循环的突破到rp过程的等待点，从十米厚大气的失控燃烧到壳层深处的碳点火，每一步都被原子核的质量、反应率、半衰期这些微观参数控制着。而我们正在一个核一个核地把这些参数测准——兰州的储存环、密歇根的Penning阱、埼玉的MR-TOF、惠州的未来装置，全在这条路上。

6个离子就能改变一颗中子星的距离估算。几十keV的质量差异就能让整条核合成路径拐弯。这就是X射线暴核物理的魅力——在最小的尺度上理解最猛烈的爆炸。
