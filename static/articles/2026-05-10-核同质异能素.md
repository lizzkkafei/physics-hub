你身体里每时每刻都有原子核待在一个不该待的位置上——能量比最低状态高，却死活不肯下来。这不是什么异常，这是原子核最常见的把戏之一。这个把戏叫同质异能素：同样的质子数，同样的中子数，唯独能量状态不同，而且那个高能状态出奇地稳定，短到纳秒，长到超过宇宙年龄。

1921年，奥托·哈恩在研究铀的衰变链时发现了一个怪事。镤-234有两种存在形式，化学性质完全一样，半衰期却天差地别——一个6.7小时，一个1.17分钟。哈恩管那个短的叫"铀Z"。他不知道自己撞上了什么，只觉得不对劲。十四年后魏茨泽克才给出解释：同一个原子核可以有不同的能量状态，它们之间的跃迁被某种选择规则卡住了，所以高能状态就能赖着不走。这是人类发现的第一个同质异能素。

```
  同质异能素原理（示意）

  高能态（异能态）        低能态（基态）
    E* ~~~~~~~~            E₀ ~~~~~~~~
      |                     |
      |  γ 衰变？           |
      |  量子规则说"不行"   |
      |  ΔJ 太大            |
      |  或者 ΔK 违禁        |
      |                     |
      +----- 被卡住 --------+

  选择规则像一道闸门：
  跃迁需要满足角动量守恒，
  不满足就"禁戒"——
  不是绝对不能，而是概率极小。
```

为什么一个激发态会卡住？核物理给了四把锁。

第一把锁是自旋。原子核的角动量像一个旋转的陀螺，异能态的陀螺转得比基态快得多。要发一个γ光子从高态跳到低态，光子必须带走角动量的差额。差额越大，需要的光子多极级越高，概率就断崖式下跌。从ΔJ=1的E1跃迁到ΔJ=4的E3跃迁，概率差了大约10的12次方。自旋异能素就是这么来的。

第二把锁叫K量子数。在变形核里，角动量沿着对称轴有一个投影，这就是K。如果异能态的K值和基态差很多，γ跃迁就必须"偷渡"——K禁戒让它几乎走不通。这类异能素叫K异能素，集中在稀土区和锕系区，那里的原子核像橄榄球一样扁长，K是个近似守恒的好量子数。最著名的例子是铪-178m2，K=16，自旋16+，半衰期31年。这个异能素后来引发了一场旷世争论，后面再说。

第三把锁是形状。有些原子核有两个人格——基态是球形，激发态却是扁的或者长的，中间隔着一道势垒。两个形状之间要翻过势垒才能互相转换，就像两个山谷之间的山脊。这种形状异能素在铅-汞核区特别多，那里中子数刚好在壳层闭合附近，球形和变形两种构型能量非常接近。2025年中国科学院上海应物所的理论工作在铅-174中预言了三种形状异能素共存——长椭球、三轴形和扁椭球——各有各的谷。

第四把锁最极端，叫裂变异能素。锕系核的裂变势垒不是一个峰，而是双峰——两个山头中间夹一个谷。原子核如果滚进了中间那个谷，就变成了超变形态（长短轴比大约2:1），被两边的高墙夹住。它出不去，唯一的路是量子隧穿到第三个谷然后裂开。镅-242m就是这样的裂变异能素，半衰期14毫秒，以自发裂变的方式衰变。1962年波利卡诺夫在杜布纳第一次发现它的时候，物理界震惊了——居然有原子核靠自发裂变来"退激"。双峰裂变势垒的图像后来成了核结构理论的一块基石，Strutinsky用壳修正方法成功解释了第二极小的存在。

```
  四类同质异能素

  ┌─────────────┬──────────────┬──────────────────┐
  │  类型       │ 卡住的原因   │  代表核           │
  ├─────────────┼──────────────┼──────────────────┤
  │  自旋异能素 │ ΔJ太大       │  180mTa (J=9-)   │
  │  K异能素    │ K禁戒        │  178m2Hf (K=16)  │
  │  形状异能素 │ 势垒隔开     │  铅区球形/变形    │
  │  裂变异能素 │ 双峰势垒     │  242mAm (14ms)   │
  └─────────────┴──────────────┴──────────────────┘
```

目前已经发现的同质异能素超过2500个，遍布核素图的每一个角落。Singh等人2022年出版的《核同质异能素图谱》第二版把它们全部收集在一起——从最短的10纳秒到最长的超过宇宙年龄。异能素在核图上的分布不是均匀的：它们像岛链一样聚集在三个区域——A≈130附近（近闭壳区）、A≈170-180（稀土变形区）、以及锕系区（裂变异能素岛）。

在这些异能素中，有一个特殊到极点的存在：钽-180m。

它是自然界最稀有的同位素。钽本身就稀少，钽-180在天然钽中只占0.012%，而钽-180全部以异能态存在——基态的钽-180半衰期只有8小时，早就衰变完了。这个异能态的J=9-，基态J=1+，ΔJ=8。要发一个γ光子跳下去，至少需要M4多极级，概率低到半衰期超过10的18次方年——比宇宙年龄长一百万倍。没人见过它衰变。2023年MAJORANA合作组在南达科他州的桑福德地下实验室用超低本底锗探测器搜索了527天，把半衰期下限推到了10的18到19次方年——终于摸到了理论预言的门槛，但衰变信号还是没看到。这个实验的附属成果很意外：钽-180m的半衰期限制已经可以用来排除某些暗物质粒子的参数空间了。钽-180m怎么在恒星里产生的至今是个谜——s-过程和p-过程都参与了，但异能态和基态在恒星等离子体中是否热平衡，决定了最终能产出多少。这个"是否热平衡"的问题，是整个天体核物理最棘手的计算之一。

```
  钽-180m：宇宙最长寿的"卡住"态

  9- (异能态)  ←── ΔJ=8 ──→  1+ (基态)
      │                         │
      │  M4 γ 跃迁              │  半衰期 ~8小时
      │  概率极低               │  (已衰变殆尽)
      │  T₁/₂ > 10¹⁸ 年        │
      │  从未被观测到衰变       │
      └─────────────────────────┘

  地下实验室搜索 → 排除暗物质参数空间
  恒星中的产生 → s/p过程 + 热平衡问题
```

说到恒星中的异能素，天体物理学家给它们起了一个专门的名字——astromer（天文异能素）。不是所有异能素都配得上这个称号。恒星的温度和密度高到可以"摇晃"原子核，让异能态和基态之间通过中间能级热平衡。如果热平衡了，异能素就失去了独立身份，只是基态的一个热布居。但如果某个异能态在特定恒星温度下依然保持独立，它就是一个astromer。2024年Misch和Mumpower在EPJ Special Topics上的综述把astromer分成三类角色：加热加速器（比基态更快释放能量）、能量电池（比基态更慢释放能量）、可观测遗迹（在稳定同位素中保留下来，发出可探测的γ射线）。

铝-26是最经典的astromer。它的基态（5+，半衰期71.7万年）发射1.809 MeV的γ射线，COMPTEL卫星在银河系中看到了这条线——这是银河系近期核合成的签名。但铝-26还有一个异能态（0+，半衰期6.3秒）。在恒星的某个温度区间，这两个态不完全热平衡，异能态作为一个独立通道存在，吞噬掉一部分铝-26然后快速衰变，改变了最终铝-26的产量。这意味着银河系中看到的1.809 MeV γ射线强度，要正确解释就必须算准异能态的热平衡。85Kr是另一个关键的astromer——s-过程分支点。它的异能态在AGB星中的行为决定了中子捕获是继续还是被β衰变截断，直接影响重元素的丰度分布。2025年Tannous和Mumpower在ApJ上的新工作专门计算了85Kr的有效热跃迁率，发现以往的处理方法在某些温度区间可能偏差显著。176Lu更有意思——它的异能态充当了s-过程的温度计，因为异能态和基态之间的布居比对温度极其敏感，从产出的176Lu/176Hf比值可以反推恒星环境的温度。

如果说天上的异能素是在帮我们读星星的日记，那地上的异能素里有一位正在改写计量学——钍-229。

这个核有一个独一无二的第一激发态：能量只有8.355电子伏。8.355 eV。其他所有已知原子核的第一激发态至少是几千电子伏，钍-229低了三个数量级。这个能量恰好落在真空紫外激光的范围内，意味着人类第一次可以用桌面激光器来操控一个原子核的量子态。

这个异能态的发现史本身就像一场漫长的猜数游戏。1976年，从γ谱学间接推断出钍-229可能有一个极低的第一激发态，估计大约3.5 eV。1990年代，更好的数据把估计压到了1 eV左右。然后又往上修正。几十年来，这个数字一直在变。直到2019年，von der Wense等人在LMU慕尼黑第一次直接观测到了这个异能态的内转换衰变。2023年，ISOLDE-CERN的团队用真空紫外光谱学方法测量了它的辐射衰变（Nature 2023），确认了能量在8 eV附近。但这还不够——要做一个核钟，你必须精确知道跃迁频率，而且要用激光直接激发它。

2024年9月，叶军团队在Nature上发表了里程碑式的结果。他们用掺镱光纤激光器产生频率梳，通过腔增强的高次谐波产生把第七次谐波推到了148 nm的真空紫外波段，然后直接激发了CaF₂晶体中钍-229核的跃迁。这是人类第一次用激光操控原子核的量子态。他们不仅测量了跃迁的绝对频率，还和同一实验室的锶-87原子钟做了直接频率比——这是核钟和原子钟之间的第一次直接比较。2026年1月，同一个团队又在Nature上发表了频率复现性的研究，证明不同CaF₂晶体样品、不同温度下的核钟频率偏差很小，固体基质核钟的复现性达到了实用水平。

```
  钍-229核钟时间线

  1976  间接推断异能态存在，能量~3.5 eV
   │
  1990s 能量估计修正至~1 eV
   │
  2019  LMU首次直接观测内转换衰变
   │

   │

   │

        → CaF₂中寿命可被激光缩短
```

核钟为什么重要？因为它测的是原子核内部的跃迁，而原子核被电子云包裹，对外界电磁场天然免疫。原子钟的精度已经到了10的负19次方量级，但它对黑体辐射、电场梯度的敏感度已经逼近极限。核钟打开了一条全新的路：用强力支配的跃迁来测时间，和电磁力支配的原子钟互校，可以检测精细结构常数α是否随时间变化——这是超越标准模型的新物理最直接的探针之一。

但同质异能素最引人注目的故事，可能是一场争论。

1999年，Carl Collins在Physical Review Letters上发了一篇论文，声称用X射线触发了铪-178m2异能素的加速衰变。铪-178m2是一个K=16的异能素，半衰期31年，每个原子核储存了2.5 MeV的能量。如果一克纯的铪-178m2在纳秒内把能量全部释放出来，功率是10的18次方瓦——一埃瓦。一克TNT释放的能量是4.2千焦，一克铪-178m2储存了1330兆焦。Collins说，用低能X射线就能"触发"这个能量释放。

DARPA被吸引了。他们启动了代号SIER（受激异能素能量释放）的项目，又搞了TRIP（触发异能素验证）实验。几年里投入了不少经费。但科学界迅速分裂成两派。2001年，Argonne国家实验室的Ahmad等人和LLNL的团队分别用同步辐射做了验证实验，什么都没看到。2003年，理论家Tkalya连发三篇论文，从基本原理论证了铪-178m2不可能被X射线触发——K禁戒太强了，X射线的能量根本找不到合适的中间态来"搭桥"。2008年，LLNL发布了一份110页的评估报告，结论是：Collins的实验统计上不显著、不可重复，利用核异能素储能"从核结构、核反应和可控能量释放的角度看都不现实"。成本方面，Pereira等人估算储能价格大约1美元1焦耳，比常规炸药贵了一万倍以上。DARPA的JASON顾问团早在1997年就下了结论——触发核异能素不可能实现，不应该尝试。

铪争论的教训不是"异能素没用"。恰恰相反——它告诉我们，异能素的能量操控需要尊重量子力学的选择规则，不存在捷径。但这个领域并没有死，只是换了一种更诚实的方式继续。

93mMo异能素的故事就是新的篇章。2018年，Chiara等人在Nature上发表论文，声称在GSI的储存环中观测到了93mMo异能素的"耗尽"——通过NEEC（核电子俘获激发）过程。NEEC的机制是：自由电子被原子核的空电子轨道俘获，俘获释放的能量传递给原子核，把它从异能态激发到更高的能级，然后从那个能级衰变到基态。这个想法在理论上提了快五十年，但从未被实验证实。Chiara的论文被Nature高调发表，立刻引发争议。多篇理论分析指出，NEEC速率不应该那么高，观察到的信号可能来自非弹性电子散射而不是NEEC。

2026年2月，Physical Review Letters上发表了新的实验结果：更精确的测量表明93mMo的异能素耗尽比2018年声称的小了几个数量级，而且信号来自非弹性核散射，不是NEEC。这不是说NEEC不存在——它是一种基本的量子过程，理论上确定存在——而是说在储存环的环境中，NEEC的信号被非弹性散射淹没了。要干净地观测NEEC，需要全新的实验方案。2025年初，中国原子能科学研究院的团队提出了一种方案：用高压缩的单能电子束与异能素离子碰撞，在无本底环境中寻找NEEC信号。ELI-NP（极端光基础设施-核物理）也在准备用激光等离子体来研究93mMo的异能素耗尽。这场追逐还在继续。

在上海交大，盛政明团队走出了一条不同的路。2022年他们在Physical Review Letters上发表了一项成果：用飞秒激光等离子体中的离子-电子库仑碰撞，实现了核异能态的飞秒泵浦。这不是"触发释放储能"，而是用激光等离子体的超快、超强环境来操控异能态的布居。这种方法的物理机制清楚——库仑碰撞的直接激发——不依赖有争议的NEEC或"触发"机制。2024年，中国工程物理研究院齐伟团队和南华大学合作，用激光等离子体产生的轫致辐射源研究了铕同核异能素的激发和退激，发表在《核技术》上。北京大学CLAPA（紧凑型激光等离子体加速器装置）也在2025年报告了激光核物理的系列进展。

回到应用，有一个同质异能素早已深入人类生活，只是我们很少从"异能素"的角度去想它——锝-99m。

"m"代表metastable，亚稳态。锝-99m是锝-99的同质异能素，自旋1/2-，基态9/2+。它发射140 keV的γ射线，半衰期6小时——既够长能把药物送到体内靶器官并完成成像，又够短不会留下长期辐射残留。全球每年大约4000万次核医学成像中，超过80%使用锝-99m。从心脏灌注扫描到骨转移探测，从肺栓塞诊断到甲状腺成像，这个异能素每天都在救人。它从哪里来？钼-99衰变产生锝-99m，而钼-99来自反应堆中铀-235的裂变。这就是为什么全球只有少数几个反应堆供应钼-99——任何一个停机都会造成锝-99m的短缺，影响数百万患者的诊断。2024年EPJ Special Topics上专门有一篇综述讨论核异能素在医学中的应用，锝-99m当然是主角，但还有铟-111m（标记白细胞定位感染）和钇-90m（治疗用，通过异能素衰变释放β粒子）等角色。

同质异能素的未来指向几个方向。核钟是最亮的星——钍-229从"是否存在"走到"频率复现性验证"只用了不到十年，固体基质核钟可能在十年内达到与最佳原子钟可比的精度。清华大学2025年实现了连续波真空紫外激光，消除了核钟的最后一个技术障碍。异能态操控方面，ELI-NP和上海交大的激光等离子体路线提供了全新工具——不是暴力触发，而是利用等离子体中电子-核相互作用的微观机制。RIKEN和FRIB等稀有同位素装置正在产生更远离稳定线的异能素，扩展已知的异能素图谱。而astromer的研究正在从逐个案例走向系统化——2025年的85Kr工作是第一步，Misch等人开发的lvlspy软件为核能级热平衡计算提供了标准化工具。

回头看来，同质异能素的故事是一个关于"卡住"的故事。原子核被量子规则卡在高能态上下不来，这个"卡住"本身成了一把钥匙——打开了核时钟、恒星考古、医学诊断和基础物理检验的大门。哈恩在1921年看到铀Z的时候不可能想象这些。他只是注意到一个数字对不上。一百多年后，那个对不上的数字已经长成了一棵大树，还在生长。
