---
title: "中子皮厚度与对称能"
category: 核结构

---
一个铅原子核有多大？这个问题听起来简单到不值一提。质子的分布用电子散射就能量得清清楚楚，五点几飞米，几十年前就知道了。但中子呢？中子不带电，电子对它视而不见。你拿光子去照，照到的是质子。你拿强子去碰，碰上的不确定性太大。一个拥有126个中子的铅核，中子到底伸出去多远？这零点几飞米的差别，居然牵动着十公里外中子星的大小。

这就是中子皮——原子核里中子比质子多出来的那一层薄薄的"皮"。它的厚度，直接连着核物质里最让人头疼的一个参数：对称能的密度依赖。而对称能怎么随密度变，又决定着中子星有多大、多重、多硬。一个原子核的皮有多厚，一颗中子星的腰有多粗，隔着十八个数量级，被同一条物理规律拴在一起。

```
  原子核截面示意（铅-208）

       n n n n n n n    <-- 中子皮（多余的中子被推到外面）
     n p n p n p n n
   n p n p n p n p n n
   p n p n p n p n p n
   n p n p n p n p n n
   p n p n p n p n p
   n p n p n p n n
     n p n p n n
       n n n n n

  R_p ~ 5.50 fm   R_n ~ 5.80 fm
  中子皮 = R_n - R_p ≈ 0.15-0.28 fm
```

为什么中子会"溢出"到外面？因为泡利不相容原理。质子和中子各自填自己的能级，中子多了，高位的就得往高处堆。但中子之间有对称能——一种来自泡利原理和核力的压力，把多余的中子往外推。这个推力有多大，对称能随密度升高的斜率就有多陡。斜率参数叫 L，L 大意味着"硬"对称能，中子压力大，皮就厚；L 小意味着"软"对称能，压力小，皮就薄。

```
  对称能与密度的关系

  E_sym(ρ)
    |
    |         /
    |        /  <-- L大（硬对称能）
    |       /
    |      /    <-- L小（软对称能）
    |     /
    |    /
    |___/________________ ρ
        ρ_0（饱和密度）

  L = 3ρ_0 × (dE_sym/dρ)|_{ρ_0}

  L大 → 中子皮厚 → 中子星半径大
  L小 → 中子皮薄 → 中子星半径小
```

2010年，美国杰斐逊实验室做了一个大胆的实验。他们不用电子的电磁力去"看"中子，而是利用弱力。弱力破坏宇称——左手电子和右手电子跟中子散射的概率不一样。这个差别极小，大约百万分之二。但只要测量这个不对称性，就能直接探测中子分布，因为弱力主要耦合中子。

这就是PREX——铅半径实验。第一次跑下来（PREX-I，2010年），精度不够，中子皮 0.33 +0.16 -0.18 飞米，误差太大说不了什么。十年后，PREX-II 用更高亮度再跑一次，2021年出结果：0.283 ± 0.071 飞米。这是有史以来最精确的铅-208中子皮测量。

但这个数字让很多人皱眉头。0.283飞米，比大多数理论预测都厚。强子散射、反质子原子、偶极极化率，这些方法给出的值大多在0.13到0.20飞米之间。PREX-II的中心值几乎是它们的两倍。

如果铅的中子皮真的这么厚，那对称能的斜率 L 就得很大——大约106 ± 37 MeV。这意味着中子物质的压力比很多人以为的高，1.4个太阳质量的中子星半径应该超过13公里。

然后2022年，同一个实验室又出了CREX的结果——钙半径实验。钙-48，20个质子28个中子，中子皮 0.121 ± 0.026 飞米。薄。比很多理论预测还薄。

问题来了。同一个实验技术，同一个实验室，铅说皮厚钙说皮薄。铅的厚皮暗示硬对称能、大 L；钙的薄皮暗示软对称能、小 L。两个结果往相反方向拉。

```
  PREX-CREX 悖论

  PREX-II (²⁰⁸Pb):  R_skin = 0.283 ± 0.071 fm  → L ≈ 106 MeV（硬）
  CREX (⁴⁸Ca):      R_skin = 0.121 ± 0.026 fm  → L ≈ 50 MeV（软）

  同一技术，同一实验室，两个核的结果互相矛盾！

  ┌──────────────────────────────┐
  │                              │
  │   PREX-II → 硬对称能 → 大L   │
  │         ╲                    │
  │          ╲  ???               │
  │           ╲                  │
  │   CREX   → 软对称能 → 小L   │
  │                              │
  └──────────────────────────────┘

  没有任何现有的核状态方程能同时满足两者
```

Frontiers 2024年的一项研究把四十多个状态方程模型全过了一遍。结果很清楚：能同时满足PREX和CREX的模型不存在。拟合CREX的（FSS2CC、V18、CBF-EI）都给出小 L；拟合PREX的（DBHF、BOB、UIX）都给出大 L。两组模型之间隔着一条鸿沟。

天文观测站在河对岸等着。2017年LIGO探测到双中子星并合的引力波GW170817，潮汐形变率约束1.4个太阳质量中子星半径约11到13公里。2024年NICER测到PSR J0437-4715的半径约11.36公里。这些数字指向紧凑的中子星，支持软对称能、小 L。PREX-II偏爱的硬对称能给出的中子星偏胖，和天文观测有些拧巴。

但话说回来，PREX-II的结果也不一定就错。0.283飞米虽然有误差棒，68%的概率落在 ±1σ 之内，这意味着有32%的概率落在之外。可能是统计波动？Sammarruca在2024年的综述里就指出了这一点。而且PREX-II也有它独特的地方：弱力探针确实比强子探针干净，强相互作用的不确定性它基本不受。

另一条线索来自偶极极化率。铅-208的电偶极极化率 α_D ≈ 20.1 fm³，这和中子皮也有紧密关联。极化率给出的中子皮大约0.13到0.19飞米，和PREX-II不太对得上。但极化率的提取也有模型依赖，不同密度泛函给出的关联不太一样。

```
  不同方法给出的²⁰⁸Pb中子皮

  方法                  R_skin (fm)
  ─────────────────────────────────
  PREX-II (弱力)       0.283 ± 0.071  ← 厚
  反质子原子            0.15 - 0.20
  偶极极化率            0.13 - 0.19
  强子散射              0.08 - 0.21
  π介子探针             ~0.11
  矮偶极共振            0.18 ± 0.035
  从头算（CC/DOM）      0.13 - 0.20   ← 理论
  ─────────────────────────────────

  PREX-II的中心值明显偏高
  其他方法聚拢在0.13-0.20 fm区间
```

从头算理论这边，情况更不利于PREX-II。耦合团簇法、散射光学模型、从头算密度泛函，这些基于手征有效场论的方法给出铅-208中子皮0.13到0.20飞米，钙-48中子皮0.12到0.15飞米。PREX-II的0.212到0.354飞米范围，已经跑出了从头算理论的边界。

所以现在有三种可能性：一是PREX-II测错了或者有系统误差被低估；二是现有理论（特别是密度泛函的同位旋矢量通道）还不够好；三是某种新物理在起作用——比如比我们想象中强得多的同位旋矢量自旋轨道力。

第三种可能性是上海交大陈列文团队提出来的。2024年他们在arXiv上发表文章指出，如果同位旋矢量自旋轨道相互作用比传统假设强四倍以上，就能同时解释铅的厚皮和钙的薄皮。因为这种力对重核和中等核的效果不同——在铅-208里它显著影响中子皮的厚度，但在钙-48里影响小得多。2025年他们进一步在协变密度泛函理论中引入强的同位旋矢量张量耦合，成功同时拟合PREX和CREX数据，不需要牺牲其他可观测量。

```
  解题思路：同位旋矢量自旋轨道力

  传统假设：同位旋矢量自旋轨道力弱
  → 一个 L 值统治所有核的中子皮
  → 铅皮厚则钙皮也厚 → 矛盾！

  新方案（陈团队）：同位旋矢量自旋轨道力强（~4×）
  → 对重核（²⁰⁸Pb）：显著增加中子皮厚度
  → 对中核（⁴⁸Ca）：影响较小，中子皮依然薄
  → 同一个模型同时拟合两个数据！

  ┌──────────┐     ┌──────────┐
  │ 传统模型  │     │ 新模型    │
  │ 弱IVSO   │     │ 强IVSO   │
  │          │     │          │
  │ Pb厚✓    │     │ Pb厚✓    │
  │ Ca也厚✗  │     │ Ca薄✓    │
  └──────────┘     └──────────┘
```

不过这个解法也有争议。Sammarruca指出，为了同时拟合PREX和CREX而人为调整同位旋矢量通道的参数，可能导致不物理的中子物质压力行为。她认为路径应该反过来——从基于真实核力的从头算出发，而不是从唯象密度泛函倒推。密度泛函里π介子的角色被严重低估了，而π介子在核力的同位旋矢量通道中才是最大的贡献者。

那么铅的中子皮到底多厚？最终答案可能来自德国美因茨。MREX——美因茨半径实验——正在MESA加速器上准备。它的目标是独立验证PREX-II的结果，精度还要再提高一倍。而且MREX计划首次测量铅-208的表面厚度参数，消除从宇称破坏不对称性提取中子皮时最大的模型依赖。PREX-II一直有一个悬而未决的问题：横向不对称性测出来接近零，这意味着可能有假不对称性混在系统误差里。MREX会专门用两种不同束流能量在MAMI加速器上测横向不对称性，把这个疑点澄清。

中国这边也在推进。兰州的CSR和惠州在建的HIAF，都是确定对称能密度依赖的重要平台。HIAF将产生远离稳定线的放射性核束，通过核反应中的中子皮敏感观测量来提取约束。北京大学的陈列文团队在中子皮与对称能领域持续深耕，他们的同位旋矢量自旋轨道力方案是目前最有竞争力的PREX-CREX消解方案之一。

```
  PREX-CREX 悖论的研究前沿

  实验方面：
  ├── MREX (美因茨/MESA) → 独立验证+双倍精度+表面厚度测量
  ├── HIAF (中国惠州) → 放射性核束+核反应探针
  ├── FRIB (美国密歇根) → 稀有同位素中子皮
  └── MAMI (美因茨) → 横向不对称性检验

  理论方面：
  ├── 陈列文团队 (上海交大) → 强IVSO/张量耦合方案
  ├── Sammarruca (爱达荷大学) → 从头算约束+批判性分析
  ├── Burgio团队 (卡塔尼亚) → 40+状态方程系统检验
  └── 多组Bayesian分析 → L参数统计推断

  天文观测：
  ├── LIGO/Virgo → GW170817潮汐形变率
  ├── NICER → PSR J0030/J0740/J0437半径
  └── 未来多信使观测 → 更紧约束
```

对称能的密度依赖为什么这么重要？因为它连着中子星的方方面面。壳-核转变密度——中子星固态外壳和液态核心的分界线——由对称能决定。L 大，转变密度低，壳就薄。直接URCA过程——中子星最快的冷却通道——的阈值也受对称能控制。L 大意味着对称能在超核密度处更高，直接URCA过程更容易发生，中子星冷却更快。但目前观测到的中子星冷却数据并不支持低质量中子星有快速中微子冷却，这反而对大的 L 构成限制。

还有潮汐形变率。两颗中子星并合时互相拉扯对方的程度，取决于星体的刚性。硬对称能的中子星更"胖"，更容易被拉变形。GW170817测到的潮汐形变率上限排除了太硬的状态方程，间接排除了太大的 L。这和PREX-II的暗示又有张力。

中子皮的厚度还影响中微子物理。中微子通过 Z 玻色子跟核子散射，散射截面取决于中子的空间分布。下一代中微子实验（比如探测超出标准模型的新物理）需要精确知道中子密度分布，否则信号和背景就分不清。中子皮差零点几飞米，中微子反冲能谱就差好几个百分点——对精密测量来说这不是小数。

```
  从中子皮到中子星到新物理

  中子皮厚度
      │
      ├──→ 对称能斜率 L
      │       │
      │       ├──→ 中子星半径 (11-14 km)
      │       ├──→ 潮汐形变率 Λ (GW170817)
      │       ├──→ 壳-核转变密度
      │       ├──→ 直接URCA冷却阈值
      │       └──→ 中子星内部成分
      │
      └──→ 中子密度分布
              │
              └──→ 中微子散射截面
                      │
                      └──→ 超出标准模型搜索
                          (暗光子/新规范玻色子)

  0.28 fm vs 0.15 fm 的差别
  → 十公里外中子星差一公里
  → 中微子实验差几个百分点
```

回顾整个故事，2010年PREX-I给出一个模糊的暗示，2021年PREX-II把它变成一个明确的悖论，2022年CREX又把矛盾激化。五年过去了，这个悖论没有被消解，反而催生出更深的问题。

最根本的问题是：我们对核力同位旋矢量通道的理解到底有多可靠？传统的协变密度泛函用 ρ 介子描写同位旋矢量力，但 π 介子才是核力同位旋部分最大的贡献者。从头算方法从手征有效场论出发，把 π 介子放在核心位置，给出一致偏小的中子皮。唯象方法从拟合数据出发，参数空间大，可以调出偏大的中子皮。两条路径给出不同的答案，但它们还没有真正对齐过——因为从头算方法还无法处理像铅-208这么重的核到PREX-II所要求的精度。

MREX会给出最关键的检验。如果它确认PREX-II的结果，那我们就得认真接受铅的中子皮确实偏厚，现有的理论框架需要大改——可能真需要陈团队提议的那种强同位旋矢量自旋轨道力。如果MREX给出更小的值，那PREX-II可能确实只是一个统计涨落，对称能回归软的一端，和天文观测和平共处。

无论哪种结果，这个故事已经展示了物理学最迷人的一面：从原子核的零点几飞米到中子星的十几公里，被一条对称能的线索串起来。你量准了铅核中子的分布，就等于给中子星的方程加了约束。反过来，引力波和中子星半径的天文观测，也在往回限制核力的同位旋部分。天上和地下，在互相校准。

而这个悖论本身，恰恰说明我们正站在一个关键点上——现有的知识和精度已经走到矛盾暴露的地方，下一步不管是实验还是理论，都会把我们的理解往前推一大步。对物理学来说，矛盾从来不是失败，而是路标。
