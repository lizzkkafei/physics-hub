这件事的开头听起来像不可能：把一个寿命只有一亿亿分之一秒（10⁻²² s）的粒子塞进原子核，让它被核力拴住——哪怕只拴那么一瞬间。拴住的时间大概也就比这粒子本身的自然寿命长一点点，但也够你测它的能量、宽度、自旋。

这个粒子叫 Σ 超子。它跟质子、中子一样由三个夸克组成，但其中一个夸克是 s 夸克——「奇夸克」。所以 Σ 超子带一个单位的奇异性（S=-1），跟 Λ 超子同级。区别在于，Σ 是同位旋三重态（Σ⁺、Σ⁰、Σ⁻），而 Λ 是同位旋单态。这个差异让 Σ 的行为跟 Λ 截然不同。

Λ 超核已经发现了三十多种。Λ 跟核子之间的力是中度吸引的，塞进原子核很自然。

Σ 超核呢？到目前为止，只有一个被明确确认：⁴_ΣHe（Σ 超氦-4）。

为什么只有一个？答案就藏在 Σ-核子相互作用的性质里。

* ΣN 力：推开的门，不是拉开的

Λ 和 Σ 虽然奇异数相同，但在核介质里，它们是两种完全不同的粒子。

Λ 可以在原子核里活很久——它的强衰变道 ΛN → NN 虽然存在，但在核介质里被泡利不相容原理压了一部分。所以 Λ 超核的宽度一般在 MeV 以下。

Σ 有一个极快的衰变通道：ΣN → ΛN。这个反应放出的能量大约 80 MeV——两个粒子的质量差。在自由空间里，Σ → Λπ 是弱衰变（因为有 ΔS=1 的选择定则），但 ΣN → ΛN 是强相互作用——时间尺度是弱衰变的一亿倍快。

所以问题不是 Σ 能不能被核力吸引，而是在 Σ 还没来得及被吸引之前，它已经通过 ΣN → ΛN 变成了别的粒子。

1988 年之前，大多数核物理学家认为 Σ 在原子核里不可能形成束缚态——宽度太大，峰根本冒不出来。

1988 年之后，他们知道这想错了。

* 第一个 Σ 超核：这个故事从 KEK 开始

1988-1989 年，日本筑波的 KEK 质子同步加速器。早野龙五（R.S. Hayano，东京大学）领导的团队做了一个实验：把停下来的 K⁻ 介子打进液态氦-4 靶。K⁻ 被 ⁴He 原子俘获，级联到低轨道，然后在核表面或内部被吸收。吸收的其中一个产物可能是 Σ 超子。

实验编号 KEK E167 [1,2]。他们在出射 π⁻ 的动量谱上看到一个峰——下面是 Σ⁺ 加 ³H 的碎裂阈值。峰的位置对应于一个束缚在 ⁴He 里的 Σ 超子：

```
    ⁴_ΣHe 的结合能 ≈ 3.2 MeV（当时估计值）
    宽度 ≈ 4.6 MeV
```

他们在 π⁺ 道（对应 Σ⁻ 产生）没有看到对应的峰。这说明这个态的同位旋 T ≈ 1/2——纯净到大约 99%。

宽度只有 4.6 MeV——远小于当时直觉预测的 20-30 MeV。怎么解释？

答案来自赤石義紀（Y. Akaishi）、原田融（T. Harada）、新村正司（S. Shinmura）和他们的合作者 [3]。他们在 1990 年用 NNNΣ 四体少体计算解释了这个谜：Σ-核势在核中心有一个*排斥芯*（repulsive core）。这个排斥芯把 Σ 的波函数往外推，降低了波函数在核心的概率密度。而 ΣN → ΛN 转换主要发生在核心（因为那里核子密度最高）。所以——排斥芯反而*保护*了 Σ 超核，让它的衰变宽度变窄。

还有一个关键因素：ΣN 势的 Lane 项——与同位旋相关的分量。在 T=1/2 道（Σ⁺ 跟 ³H 耦合），这个项是吸引的，足以形成束缚态。在 T=3/2 道，它是强排斥的。⁴He 正好提供了一个 T=1/2 的纯净环境。

* BNL 确认：从"疑似"到"确定"

KEK 的信号有说服力吗？有。但同行需要独立的确认。1996 年，Brookhaven 国家实验室的 AGS 加速器上，长谷川智久（T. Nagae，当时在 KEK，后在京都大学）领导的 BNL E905 实验用了一个不同的方法证明 ⁴_ΣHe 是真实存在的 [4]。

他们用飞行中的 K⁻（600 MeV/c）打 ⁴He，看 (K⁻,π⁻) 反应——不是停下来的 K⁻，这避免了停在液体氦里引起的级联效应复杂问题。1998 年发表在 Physical Review Letters 上的结果是明确的：

```
    B_Σ⁺(⁴_ΣHe) = 4.4 ± 0.3(stat) ± 1(syst) MeV
    Γ(⁴_ΣHe) = 7.0 ± 0.7(stat) +1.2/−0.0(syst) MeV
    J^π = 0⁺, T ≈ 1/2
```

这个结合能跟 Harada 团队用 SAP-1 势（基于 Nijmegen model-D 的单玻色交换势）预测的 4.6 MeV 惊人地吻合 [3]。

从此，⁴_ΣHe 成了确认的 Σ 超核——目前仍然是唯一被广泛确认的一个。

* 为什么找第二个这么难

有了 ⁴_ΣHe，你会自然想：下一个呢？⁷_ΣLi？⁹_ΣBe？¹²_ΣC？

这几个都有人找过。没有人找到。

原因在上面的分析里已经埋好了：排斥芯 + Lane 项 = 一个只在特定同位旋条件下才管用的保护机制。⁴He 作为靶核之所以特别，是因为 Σ⁺ 跟 ³H 残余核之间天然形成 T=1/2。在更重的核上，比如 ⁶Li，残余核 ⁵He 有更复杂的同位旋结构——T=1/2 和 T=3/2 通道混合，排斥分量变大。

用一个比喻：⁴He 像是专门给 Σ 超子准备的一个小小的安全气囊——尺寸刚够，同位旋对得准。跳到更大的核，这个气囊要么太大（波函数进核心太多），要么同位旋结构不纯（排斥道的作用力盖过了吸引道）。

* FINUDA 的系统性搜索

意大利 Frascati 国家实验室的 DAΦNE Φ-介子工厂有一个专门做超核的实验叫 FINUDA（FIsica NUcleare a DAΦNE）。Φ→K⁺K⁻ 衰变提供纯度极高的低能 K⁻，停在不同靶材上产生超核。

FINUDA 在 2011 到 2015 年间系统地搜索了 p 壳核上的 Σ 超核 [5,6]。他们在 ⁶Li、⁷Li、⁹Be、¹³C、¹⁶O 上做了 (K⁻_stop, π⁺) 和 (K⁻_stop, π⁻) 测量。两个关键结果：

第一，Σ⁻p 发射率的测量（2015 年 PRC）显示，在比 ⁴He 重的核上，K⁻ 吸收产出的 Σ 超子大多数通过准自由过程跑掉了——没有形成束缚态 [5]。

第二，π⁻Σ⁺/π⁺Σ⁻ 产额比在这些核上跟自由氢靶的值偏差显著——这说明介质效应很强，但这些效应似乎不利于束缚态形成 [6]。

FINUDA 没有找到任何新的 Σ 超核束缚态。这个否定性结果本身就是重要的信息：它把「为什么只有 ⁴_ΣHe」从一个经验观察变成了一个有理论解释的事实。

* 日本物理学会的综述：从原子到中子星，一条线穿过 Σ

2018 年，原田融等人在日本物理学会志上发表了一篇重要综述 [7]：《シグマハイパー核はどこまでわかったか？——原子、原子核、中性子星で紐解くΣ粒子の謎》（我们对 Σ 超核了解多少——通过原子、原子核和中子星解开 Σ 粒子的谜团）。这篇综述把三个不同尺度的物理串在了一起。

尺度一：Σ⁻ 原子。当一个 Σ⁻ 被原子的库仑场捕获、级联到低轨道，它的 X 射线能级位移和宽度可以直接反推 Σ-核光学势的强度和虚部。Batty、Friedman 和 Gal 在 1997 年的经典综述 [8] 中从 Σ⁻ 原子数据提取出了光学势参数：势的实部约 20-30 MeV 上下，是个排斥势——不是吸引势。

尺度二：Σ 超核。就是 ⁴_ΣHe 和寻找其他 Σ 束缚态的努力。在这个尺度，关键的变量是 ΣN → ΛN 转换宽度和排斥芯的平衡。

尺度三：中子星。中子星内部密度达到 2-3 倍核密度时，中子费米能高到足以让 Σ⁻ 超子取代电子参与 β 平衡——Σ⁻ 比电子重，但带负电，在高密度下不用被压到那么高的动量。这叫「Σ⁻ 的门槛效应」。原田等人的综述把这三个尺度的约束整合进了一个统一框架 [7]。

* J-PARC E40：第一次直接摸到 ΣN 力

讨论了几十年的 ΣN 力——排斥的、还是吸引的、有多依赖自旋和同位旋——核心实验依据一直来自 ⁴_ΣHe 这一个束缚态。这就像通过看一座桥的振动模式来反推每一根钢索的拉力——能做，但不确定度大。

真正直接的办法是 Σ-核子散射实验。把 Σ⁺ 打在质子靶上，看角度分布。但 Σ 的寿命太短（cτ 只有几厘米），传统束流靶实验几乎不可能。

J-PARC E40 实验室解决了这个问题 [9,10]。他们用 π⁺ 束打液态氢靶产生 Σ⁺，再用 CATCH 径迹探测器追踪产出的 Σ⁺ 在周围塑料闪烁体中的散射。2022 年，南村卓也（T. Nanamura）等人在 PTEP 上发表了最终分析结果 [9]：

从 4.9×10⁷ 个标记的 Σ⁺ 中，提取出约 2400 个弹性散射事件，动量范围 0.44-0.80 GeV/c。这是人类第一次对 Σ⁺p 散射做*相移分析*。

主要发现：

```
    ³S₁ 道（自旋三重态，I=3/2）：中等排斥
    相移 20° < |δ(³S₁)| < 35°

    ¹P₁ 道（自旋单态）：弱吸引
```

这两个结果合起来淘汰了一整类夸克集团模型（FSS 和 fss2）——这些模型预测 ³S₁ 道的排斥太强，导致微分截面比实验数据高一倍以上。同时，基于介子交换的 Nijmegen 扩展软芯（ESC）模型通过了检验——它的预测跟 E40 数据吻合得很好 [9,10]。

E40 合作组约 71 名成员，主要来自日本各大学（东北大学、京都大学、大阪大学等）和 JAEA。这是 ΣN 散射实验从统计误差为王的时代进入精度时代的标志。之前的 KEK E251/E289 只有约 30 个事件——E40 把这个数字放大了约 80 倍。

* 排斥势的独立确认：E10 的 DWIA 分析

J-PARC E10 实验的主要目标是用 (π⁻,K⁺) 反应找中子过剩的 Λ 超核 ⁶_ΛH。但在准自由 Σ 产生区——也就是 Σ⁻ 还没被核力抓住就被打出来的区域——谱形本身编码了 Σ-核势的信息。

2018 年，原田融（当时在大阪电气通信大学）、本田亮太郎（R. Honda）和平林義治（Y. Hirabayashi）用扭曲波冲量近似（DWIA）分析了 E10 的 ⁶Li(π⁻,K⁺) 数据 [11]。他们把 ⁵_ΣHe 系统（Σ⁻ 被 ⁵He 残余核散射）的谱形拟合出来，得到 Σ-核光学势的强度和虚部：

```
    V_Σ = +30 ± 10 MeV（实部排斥）
    W_Σ =  −26 ± 2 MeV（虚部吸收——与 ΣN→ΛN 转换相关）
```

V_Σ=+30 MeV 是强排斥——跟从 Σ⁻ 原子数据推出的基本一致 [8]，也跟 E40 测到的 ³S₁ 排斥相移一致。不同方法、不同系统、不同能量——三条线汇聚到一个结论：Σ-核势在核中心是*排斥*的。

* 手征 EFT：从头算 ΣN 力

排斥这个结论对不对，不能只靠唯象模型说了算。你得从量子色动力学（QCD）——描述夸克和胶子相互作用的基本理论——推导出来。

这就是手征有效场论（chiral EFT）做的事。2023 年，Haidenbauer、Meißner、Nogga 和 Le（德国于利希研究中心和波恩大学）发表了第一个达到次次领头阶（N²LO）的超子-核子（YN）手征势 [12]。它包括 ΛN 和 ΣN 道，采用半局域动量空间（SMS）正规化方案。

几个要点：

第一，Σ⁺p 散射（纯 I=3/2，没有 ΛN 耦合的麻烦）是检验 SU(3) 味对称性的最佳窗口。在精确的 SU(3) 极限下，I=3/2 的 NN 力和 ΣN 力属于同一个多重态。N²LO 手征势对 J-PARC E40 的 Σ⁺p 微分截面的拟合很好（χ²≈15.6，36 个低能数据点）——说明 SU(3) 在低能强子物理中确实是好的近似。

第二，2024 年同一组人发表了第一个*一致性包含*手征 YNN 三体力的轻超核计算 [13]。ΛN-ΣN 耦合——也就是 Λ 和 Σ 之间的相互转换——是理解 Λ 超核结合能的关键。单靠 ΛN 两体力，Λ 超核总是欠束缚的。ΣN 道的耦合和三体力一起提供了额外的吸引。⁴_ΛH、⁴_ΛHe 和 ⁵_ΛHe 的结合能在包含 YNN 三体力后首次被同时完好地复现 [13]。

这对 Σ 超核意味着什么？它说明 ΣN 力不是孤立的——它通过耦合道动态跟 ΛN 力纠缠在一起。你不能把 Σ 超核单独理解成「Σ 被核力抓住」；它是 Σ 和 Λ 两组道在量子力学层面上混合的结果。⁴_ΣHe 的窄宽度部分就是因为 T=1/2 道的这个混合为 Σ 波函数提供了一个「避难所」。

* 中子星：Σ 在十公里尺度上做什么

把视角从飞米（10⁻¹⁵ m）拉到十公里。中子星的核心密度是核密度（ρ₀≈2.8×10¹⁴ g/cm³）的 2-3 倍。在这种条件下，中子费米能上推到几百 MeV。

Λ 超子最轻（1116 MeV），最先出现——大约在 2-3 ρ₀。Σ 超子稍重（约 1190 MeV），但因为 Σ⁻ 带负电，在 β 平衡条件下可以替换高能电子，所以 Σ⁻ 的门槛密度可能比 Λ 还低。

但这是假设 Σ-核子作用*在核介质中*是吸引的前提下。实验告诉我们——在正常核密度（ρ₀）附近，Σ-核势是*排斥*的：V_Σ≈+30 MeV [8,11]。这就从根本上改变了 Σ⁻ 在中子星里出现的时间线。

Jinno、Murase 和 Nara 在 2025 年的工作 [14] 中系统地处理了这个问题。他们用手征 EFT 导出的 YN + YNN 相互作用（包括 ΛN、ΣN 和 ΛN-ΣN 耦合）构建中子星物质的状态方程。核心发现：

通过调节 YNN 三体力的低能常数，可以*同时*满足三个约束——(a) 超核谱学数据、(b) 重离子碰撞中的 Λ 流、(c) 经验 Σ 势（+30 MeV）。这个一致性不是显然的——同一个低能常数在 Λ 系统和 Σ 系统中要同时工作，才算真正的成功 [14]。

在这个框架下，Σ⁻ 在中子星物质中的出现被推到更高密度（>3-4 ρ₀），甚至被完全抑制。这对解决「超子疑难」——也就是为什么含超子的状态方程太软、不足以支撑 2 个太阳质量的中子星——是关键性的。

Tsubakihara、Ohnishi 和 Harada 在 2024 年更新的工作 [15] 补充了一个重要的细节：Σ 势的*同位旋矢量*部分（跟 ρ 介子交换相关）如果比 SU(3) 对称值小——大概降为原来的 1/2 到 2/3——那么 Σ⁻ 仍然可以在 2-3 ρ₀ 处出现。但即便这样，它的丰度被极大的排斥实部压制。Σ⁻ 在中子星核心里至多占几个百分点——远不足以单独驱动超子疑难 [15]。

* J-PARC E13：在更高动量找激发态

还有一个悬而未决的问题：⁴_ΣHe 有激发态吗？

低动量的 (K⁻,π⁻) 反应（如 E167 和 E905 用的 600 MeV/c）主要布居的是 Σ 占据 s 轨道的基态。如果要加强 Σ 占据更高轨道（p 轨道、d 轨道）的成分，需要用更高动量的束流。

J-PARC E13 实验在 2015 年把 K⁻ 束流动量推到 1.5 GeV/c，打 ⁴He 靶，用高分辨率的 SKS 谱仪做 (K⁻,π⁻) 测量 [16]。中川真里奈（M. Nakagawa，大阪大学）在这项努力中被多次提到。数据分析仍在进行中，目标是找到 ⁴_ΣHe 的自旋-轨道伙伴态——也就是 J^π=1⁻ 或 2⁺ 的态，对应 Σ 在 p 波或 d 波上。如果能测到，它将第一次给出 Σ 的自旋-轨道耦合强度——这是当前 ΣN 势中最未知的参数之一。

* 这张图的现状：我们站在哪里

把所有这些拼起来，得到的是这样一幅图景：

```

  Σ 超核研究的层次结构

  │ 正在进行的搜索：E13 激发态、⁵_ΣHe 再分析    │
  └─────────────────────────────────────────┘

  第二层：ΣN 力的实验室约束
  ┌─────────────────────────────────────────┐
  │ E40 Σ⁺p 散射：³S₁ 排斥 |δ|≈20-35°        │
  │ E10 准自由谱：V_Σ = +30 ± 10 MeV        │
  │ Σ⁻ 原子 X 射线：排斥实部约 20-30 MeV      │
  └─────────────────────────────────────────┘

  第三层：第一性原理理论
  ┌─────────────────────────────────────────┐
  │ Chiral EFT N²LO YN (Haidenbauer et al.)  │
  │   对 E40 数据拟合良好                    │
  │ Chiral EFT + YNN 三体力 (Le et al. 2024) │
  │   同时复现 Λ 和 Σ 超核数据               │
  │ NNNΣ 四体少体计算 (Harada et al. 1990)   │
  │   预测了排斥芯和窄宽度                   │
  └─────────────────────────────────────────┘

  第四层：天体物理意义
  ┌─────────────────────────────────────────┐
  │ Σ⁻ 在 NS 中受排斥势压制                   │
  │ 三体力可同时解释超核数据 + 支撑 2 M☉ NS   │
  │ 超子疑难需要 Λ、Σ、Ξ 的全局一致处理       │
  └─────────────────────────────────────────┘

```

现在唯一确认的 Σ 超核——⁴_ΣHe——已经找到了三十多年。它不再是一个边缘的奇迹信号，而是一个被散射实验、原子 X 射线数据和从头算理论交叉验证的标准化输入。

寻找第二个 Σ 超核的努力——在 FINUDA 之后，暂时停下来了。这不是失败，而是理论预测和实验数据之间的一种收敛：Σ 超核确实只在非常特定的条件下存在。排斥芯和窄宽度的物理机制——最初被 ⁴_ΣHe 揭示出来——现在被散射实验和格点 QCD 的独立框架所确认。这条线索已经不再依靠一个孤立的信号。

接下去有两个方向会推动 Σ 超核往前走。一个是 E13 激发态的数据分析——如果看到 p 波束缚态，Σ 的自旋-轨道力将被直接测定。另一个是手征 EFT 在更高阶上的 YNN 三体力计算——目前只用十重态饱和方法估计了低能常数，直接格点 QCD 算三体力是下一步的目标。

Σ 超核让我们看到的是：强相互作用在奇异夸克扇区有多精细。一个排斥芯的位置、一个 Lane 项的符号、一个三体力的份额——差一点就决定了这个粒子能不能在原子核里多住一刻。这扇门只开了一条极小极小的小缝，但目前穿过去的光是亮的。
